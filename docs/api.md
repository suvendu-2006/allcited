# Allcited — API Reference & Integration Protocol

> Production API specification for Allcited. All endpoints are versioned with the `/v1` prefix and support deterministic error envelopes, Server-Sent Events (SSE) streaming, and strict citation payloads.

---

## 1. Global Conventions & Standards

### 1.1 Base URLs
- **Production Cloud (Hugging Face Spaces):** `https://subh-007-allcited-api.hf.space`
- **Local Development / Docker:** `http://localhost:8000`

### 1.2 Request Headers
- `Content-Type`: `application/json` (or `multipart/form-data` for file uploads).
- `Authorization`: `Bearer <clerk_jwt_token>` (required for `/v1/library/*` persistence endpoints; optional for guest querying).
- `X-Request-ID`: Optional client-supplied UUID string. If omitted, the server automatically generates one. All responses include an `X-Request-ID` header.

### 1.3 Standard Error Envelope Contract
All HTTP error responses (4xx and 5xx) conform to a strict, standardized error envelope:

```json
{
  "error": {
    "code": "plan_limit_reached",
    "message": "Free tier limit of 3 saved library documents reached. Upgrade to Pro for unlimited document storage.",
    "request_id": "8f3b2a1c-5d4e-4f7a-9b1e-6c8a7b9e0f1d"
  }
}
```

### 1.4 Error Code Catalog

| Error Code | HTTP Status | Description & Remediation |
| :--- | :---: | :--- |
| `doc_unreadable` | 400 | File is corrupt, password-protected, or yielded 0 readable text. |
| `url_blocked` | 400 | SSRF guard blocked the request (private IP, loopback, link-local, or cloud metadata). |
| `validation_error` | 422 | Request payload failed Pydantic schema validation. |
| `unauthorized` | 401 | Missing `Authorization: Bearer <token>` header on a protected route. |
| `token_expired` | 401 | Clerk JWT token timestamp has expired. Re-authenticate via frontend. |
| `invalid_token` | 401 | Clerk JWT signature verification failed or subject (`sub`) claim is missing. |
| `forbidden` | 403 | Attempted to access or mutate a resource owned by another user (BOLA / IDOR defense). |
| `plan_limit_reached` | 402 | Free tier cap reached (upload > 10 MB, precision mode, or saved documents > 3). |
| `doc_too_large` | 402 | File exceeds max permitted size (Free: 10 MB, Pro: 100 MB). |
| `session_not_found` | 404 | In-memory session expired or invalid session ID. Document must be re-ingested. |
| `free_tier_busy` | 429 / 503 | Concurrency ceiling reached or Groq cloud rate limit exceeded. |
| `ollama_unreachable` | 502 / 503 | Local Ollama daemon unreachable at configured `OLLAMA_BASE_URL`. |
| `injection_flagged` | 200 | Document attempted prompt injection; neutralized into passive data. |

## 2. Server-Sent Events (SSE) Streaming Protocol

The `POST /v1/query` and `POST /v1/summarize` endpoints stream real-time updates over HTTP text streams (`Content-Type: text/event-stream`).

### Event Stream Lifecycle

```
Client                        Server (/v1/query)
  │                                    │
  │─── POST /v1/query ────────────────►│
  │                                    │
  │◄── event: route ───────────────────│ (Query intent classification)
  │◄── event: cache ───────────────────│ (Optional: Semantic cache hit)
  │◄── event: rewrite ─────────────────│ (Optional: Query decomposition)
  │◄── event: token ───────────────────│ (Generated delta token 1)
  │◄── event: token ───────────────────│ (Generated delta token 2)
  │◄── event: token ───────────────────│ (...)
  │◄── event: citations ───────────────│ (Array of verified citation receipts)
  │◄── event: done ────────────────────│ (Final telemetry and closing frame)
```

### Event Payload Schema

#### `event: route`
Emitted immediately after query intent classification:
```json
{
  "mode": "hybrid",
  "hyde_used": false,
  "confidence": 0.94
}
```

#### `event: cache`
Emitted if an evaluated query with cosine similarity $\ge 0.96$ matches in the semantic cache:
```json
{
  "hit": true,
  "similarity": 0.985,
  "cached_at": "2026-10-29T18:40:12Z"
}
```

#### `event: rewrite`
Emitted when an agentic sufficiency loop or multi-aspect query breaks into sub-queries:
```json
{
  "sub_queries": [
    "What is the annual leave allowance under Section 4?",
    "What is the separation notice period under Rule 63.7.4?"
  ]
}
```

#### `event: token`
Delivers raw incremental markdown text chunks generated by the LLM:
```json
{
  "delta": "Under Rule 63.7.4 [S1], unused leave balances "
}
```

#### `event: citations`
Emitted after generation passes the citation audit post-pass. Contains the complete array of receipt cards backing the response:
```json
[
  {
    "id": "chunk_7482",
    "source_num": 1,
    "document_name": "Employee_Handbook_2026.pdf",
    "page": 14,
    "section_breadcrumb": "Employee Handbook > Section 4: Benefits > 4.2 Leave Encashment",
    "text": "Employees may carry forward up to 10 unspent annual leave days into the subsequent fiscal calendar pursuant to Rule 63.7.4.",
    "is_ocr": false,
    "is_two_hop": true,
    "added_reason": "Defined in rule:63.7.4"
  }
]
```

#### `event: done`
Signals stream termination and delivers latency and token metrics:
```json
{
  "session_id": "sess_8f3a9d2c",
  "tokens_generated": 142,
  "prompt_tokens": 1280,
  "latency_ms": 1140,
  "provider": "groq",
  "model": "llama-3.3-70b-versatile"
}
```

## 3. Core REST Endpoints

### 3.1 Health & Diagnostics

#### `GET /v1/health`
Liveness probe checking service status and active configuration.
- **Response (200 OK):**
```json
{
  "status": "ok",
  "environment": "production",
  "provider": "groq",
  "version": "1.0.0"
}
```

#### `GET /v1/readyz`
Deep readiness probe asserting memory stores, models, and external databases.
- **Response (200 OK):**
```json
{
  "status": "ready",
  "database": "healthy",
  "cache": "active",
  "vector_store": "ready",
  "cross_encoder": "loaded"
}
```

---

### 3.2 Ingestion

#### `POST /v1/ingest`
Uploads and indexes documents (`multipart/form-data`). Supported extensions: `.pdf`, `.docx`, `.pptx`, `.xlsx`, `.html`, `.md`, `.txt`.

- **Form Fields:**
  - `file`: Binary file stream (max 10 MB for Free, 100 MB for Pro).
  - `ocr_provider` *(optional)*: `tesseract` (default) or `easyocr`.

- **Response (200 OK):**
```json
{
  "session_id": "sess_e9c381a7b",
  "document_name": "Company_Policy_Manual.pdf",
  "chunks_count": 48,
  "total_tokens": 13940,
  "pages_scanned": 12,
  "ocr_used": false,
  "references_found": 8
}
```

#### `POST /v1/ingest/url`
Fetches and indexes remote web content. Protected by the SSRF defense subsystem.

- **Request Body:**
```json
{
  "url": "https://example.com/company-handbook"
}
```

- **Response (200 OK):**
```json
{
  "session_id": "sess_1a8f9c0e",
  "document_name": "company-handbook",
  "chunks_count": 22,
  "total_tokens": 6800,
  "ocr_used": false,
  "references_found": 3
}
```

---

### 3.3 Query & Generation

#### `POST /v1/query`
Streams grounded answers with inline citations (`[S1]`, `[S2]`). Returns `text/event-stream`.

- **Request Body:**
```json
{
  "session_id": "sess_e9c381a7b",
  "question": "What is the notice period for senior managers?",
  "top_k": 5,
  "stream": true,
  "byok": {
    "provider": "groq",
    "api_key": "gsk_...",
    "model": "llama-3.3-70b-versatile"
  }
}
```

#### `POST /v1/summarize`
Generates a structured, hierarchical map-reduce executive summary of the ingested document.

- **Request Body:**
```json
{
  "session_id": "sess_e9c381a7b",
  "max_bullets": 5
}
```

- **Response:** SSE stream delivering markdown overview with bracketed section receipts.

---

### 3.4 Library & Document Persistence

Protected endpoints requiring `Authorization: Bearer <token>`.

#### `POST /v1/library/save`
Persists an in-memory document session into the user's permanent Supabase library shelf. Protected against BOLA/IDOR attacks.

- **Request Body:**
```json
{
  "session_id": "sess_e9c381a7b",
  "title": "Q3 Financial Disclosures"
}
```

- **Response (200 OK):**
```json
{
  "document_id": "doc_019a8f4c",
  "user_id": "user_2a9b4c6d",
  "title": "Q3 Financial Disclosures",
  "chunk_count": 48,
  "created_at": "2026-10-29T19:00:00Z"
}
```

#### `GET /v1/library/documents`
Lists all saved documents for the authenticated user.
- **Response (200 OK):**
```json
[
  {
    "document_id": "doc_019a8f4c",
    "title": "Q3 Financial Disclosures",
    "chunks_count": 48,
    "file_size_bytes": 148290,
    "created_at": "2026-10-29T19:00:00Z"
  }
]
```

#### `DELETE /v1/library/documents/{document_id}`
Deletes a document and all associated chunks from the library.
- **Response (200 OK):**
```json
{
  "status": "deleted",
  "document_id": "doc_019a8f4c"
}
```

#### `POST /v1/library/query`
Cross-document semantic synthesis across the user's entire document collection.

- **Request Body:**
```json
{
  "question": "Compare severance rules across our 2024 and 2026 policies",
  "document_ids": ["doc_019a8f4c", "doc_018e7d2b"]
}
```

### 3.5 Telemetry & Platform Monitoring

#### `GET /v1/trace/{session_id}`
Retrieves detailed, step-by-step latency, retrieval scores, and execution events for a question.
- **Response (200 OK):**
```json
{
  "session_id": "sess_e9c381a7b",
  "steps": [
    {"name": "pii_masking", "latency_ms": 1.2},
    {"name": "semantic_cache_lookup", "latency_ms": 3.4, "result": "miss"},
    {"name": "bm25_retrieval", "latency_ms": 1.1, "candidates": 10},
    {"name": "faiss_retrieval", "latency_ms": 4.2, "candidates": 10},
    {"name": "reciprocal_rank_fusion", "latency_ms": 0.8},
    {"name": "cross_encoder_rerank", "latency_ms": 84.1, "retained": 5},
    {"name": "two_hop_expansion", "latency_ms": 2.1, "added_chunks": 1},
    {"name": "generation_stream", "latency_ms": 820.0}
  ],
  "total_latency_ms": 916.9
}
```

#### `GET /v1/cache/stats`
Reports semantic cache hit ratios and total tokens saved.
- **Response (200 OK):**
```json
{
  "total_lookups": 1420,
  "hits": 384,
  "hit_ratio": 0.27,
  "tokens_saved": 492000,
  "cost_avoided_usd": 0.88
}
```
